# 社区长者智能手环告警家属确认与上门处置平台

面向社区独居老人照护场景的演示系统：手环绑定建档 → 告警接入与智能研判 → 家属确认 → 社区派单上门 → 急救/物业联动 → 就医与回访 → 事件闭环复盘 → 照护画像沉淀。

技术栈：**React 18 + TypeScript + Vite + Zustand + React Router**，纯前端单页应用，数据为本地 mock（Zustand 内存态，刷新后重置）。

## 功能总览

- **手环绑定建档**：记录老人姓名、住址、慢病、紧急联系人（多顺位）、常用活动范围（电子围栏依据）、设备电量、佩戴习惯、个性化告警阈值（跌倒灵敏度 / 心率上下限 / 静止时长 / 离线时长 / 围栏）。
- **五类告警接入**：跌倒、心率异常、长时间静止、离家未归、设备离线；自动叠加夜间、浴室、低电等风险标签。
- **智能处置流程**：根据告警类型、最近活动轨迹、历史误报次数、家属联系方式、社区值班人员动态生成处置步骤，并按风险权重排序待处置队列。
- **家属端**：确认误报 / 请求电话核实 / 要求上门 / 直接联系急救；查看各联系人通知与响应状态。
- **社区端**：电话核实结果登记、向附近值班网格员派单、上门结果登记（平安 / 受伤 / 无人开门）、一键联动 120（自动交接地址、门禁、慢病史）、现场化解、送医确认、回访登记、闭环复盘。
- **上门信息一页齐**：老人地址、门禁信息、钥匙托管、责任/附近网格员、上一次回访记录、慢病与佩戴习惯。
- **同一事件时间线**：告警、家属确认、电话、派单、上门、升级联动、送医、回访、闭环全部沉淀在同一事件内。
- **闭环复盘**：事件定性（设备误报 / 照护缺口 / 真实风险）、误报原因、设备调整建议、阈值调整记录、家属响应时长、社区处置时效。
- **照护画像**：连续无人响应、频繁离线、多次上门无人自动计数并更新画像；社区可据此调整巡访频次、设备维护安排与家属提醒方式。

## 本地启动

### 方式一：Docker / Compose（推荐，一键启动）

```bash
docker compose up -d --build
# 打开 http://localhost:8080
```

停止：`docker compose down`

### 方式二：本地开发（Node 18+，推荐 Node 22）

```bash
npm install        # 如遇 npm 缓存权限问题，可追加：--cache ./.npm-cache
npm run dev        # http://localhost:5173
```

生产构建与本地预览：

```bash
npm run build      # TypeScript 类型检查 + Vite 构建到 dist/
npm run preview    # http://localhost:4173
```

## 验证方式（建议操作路径）

1. **待处置队列优先级**：打开「处置总览」，可见 INC-20261003-01（夜间浴室跌倒 + 家属未响应）排在最前并标记「紧急」。
2. **家属确认**：切到「家属端」（身份张小明）→ 进入该事件 → 点「要求上门」；右侧可见联系人通知/响应状态。
3. **社区上门处置**：切回「社区端」→ 进入事件 → 登记电话「无人接听」→ 向网格员「周敏」派单 → 「登记上门结果」选择受伤/无人开门，观察风险标签与处置流程自动推进。
4. **急救联动**：点击「联动 120」，时间线生成含地址、门禁、慢病史的交接记录；再点「确认已送医」。
5. **回访与闭环**：登记回访 → 「事件闭环复盘」选择定性（设备误报/照护缺口/真实风险），填写误报原因与阈值调整 → 提交后自动计算家属响应时长、社区处置时效并跳转复盘页。
6. **画像沉淀**：打开「闭环复盘与画像」或老人档案页，查看无人响应次数、30 天离线、上门无人计数及巡访频次/设备维护/家属提醒方式的调整；可在老人详情页直接调整告警阈值。
7. **模拟新告警**：社区端在「告警事件」页点「模拟手环新告警」，选择老人、类型与位置（如输入「浴室」），系统按当前时间自动判定夜间、按电量自动打低电标签并生成新事件与处置流程。
8. **绑定新老人**：「老人档案」→「绑定新老人/手环」，填写姓名、住址、门禁、钥匙托管、慢病、联系人、佩戴习惯与阈值后进入档案详情。

## 目录结构

```
src/
├── types.ts          # 领域模型（老人/事件/联系人/阈值/画像等）
├── mockData.ts       # 4 位老人、3 名网格员、5 起示例事件
├── flow.ts           # 处置流程生成、风险权重、时间工具
├── store.ts          # Zustand：告警全生命周期操作与画像沉淀
├── components/ui.tsx # 标签、状态徽标、电量、弹窗等基础组件
└── pages/            # 总览 / 事件列表 / 事件详情 / 档案列表 / 档案详情 / 复盘画像
```
